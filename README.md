<h1 align="center">
  Sorting Visualizer
</h1>

<h4 align="center">
  An interactive web application to visualize popular sorting algorithms.
</h4>


## ✨ Features

- 📊 Visualize sorting algorithms using animated bars
- 🎯 Choose different sorting algorithms
- 📏 Adjust array size
- ⚡ Control sorting speed
- 🔀 Generate random, sorted, or reversed arrays
- 🔄 Reload and reset the visualization

## 🧮 Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## 🛠️ Built With

- HTML
- CSS
- JavaScript
